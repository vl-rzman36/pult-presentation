# Пульт — приложение для выступлений

Пульт помогает вести мероприятие с одного рабочего экрана: переключать презентации и видео, управлять фоновой музыкой и показывать зрителям отдельное окно без служебных заметок.

Текущая версия: **2.5.2**, Windows x64. Проект активно развивается.

## Возможности

- Мероприятия с отдельными материалами, заметками, плейлистами и настройками.
- Разделы сценария и перетаскивание материалов и разделов.
- PDF, изображения, отдельные видео и импорт PPTX.
- Экран ведущего и отдельный экран зрителей; предварительная подготовка следующего материала.
- Заглушка, заметки, миниатюры страниц и таймер.
- Музыкальные плейлисты: повтор, один трек и стоп, случайный порядок и другие режимы.
- Плавное включение и затухание музыки, отдельная громкость треков.
- Приостановка фоновой музыки на время видео.
- Переход к следующему материалу по порядку разделов.
- Настройки видео: запуск при показе, громкость, повтор, последний кадр / заглушка / следующий материал после окончания.
- Пульт на телефоне через локальную сеть и QR-код.
- Экспорт мероприятия в файл `.pult` со всеми материалами и музыкой.

## Запуск

Скачайте ZIP со сборкой Windows из раздела **Releases**, распакуйте всю папку и запустите `PultPresentation.exe`. Установка Node.js для готовой сборки не нужна.

Для запуска из исходников нужны Windows и Node.js с npm:

```sh
npm ci
npm start
```

## Мероприятия и перенос

Список мероприятий находится сверху слева. Меню рядом позволяет создавать, переименовывать, копировать и удалять мероприятия, экспортировать и открывать пакеты. Изменения сохраняются автоматически.

Создайте разделы сценария и перетаскивайте материалы за ручку слева. Нажатие на название раздела открывает его название и заметку для редактирования.

Чтобы перенести выступление, экспортируйте `.pult` на флешку и откройте его в приложении на другом компьютере. Импорт копирует материалы локально, поэтому после завершения флешку можно отключить. Для переноса самого приложения скопируйте всю распакованную папку сборки.

Удаление материала из сценария не удаляет исходный файл с диска. Для переключения мероприятий закройте экран зрителей.

## Экран зрителей

Кнопка «Экран» вверху открывает список подключённых мониторов по имени и разрешению. Можно выбрать внешний монитор, любой конкретный экран или отдельное окно на основном. «Выбрать / перенести показ» сохраняет настройку на этом компьютере и переносит уже открытое окно, сохраняя материал. «Тест экрана» проверяет выбранное устройство.

При отключении выбранного экрана окно показа скрывается, видео, музыка и таймер приостанавливаются. При включённом автоматическом возврате окно появляется после подключения того же экрана; воспроизведение остаётся на паузе. Если автоматический возврат выключен, нажмите «Выбрать / перенести показ» вручную. Можно сразу выбрать другой подключённый монитор.

Экран определяется по системному идентификатору; при его изменении используется уникальное совпадение имени. При неоднозначном совпадении приложение ожидает ручного выбора. Логика отключения и возврата проверена программной имитацией событий Windows; физическое переподключение конкретного проектора стоит проверить на репетиции.

## Расположение команд

В верхней строке находятся инструменты, выбор экрана, заглушка и открытие/закрытие показа. Добавление материалов, отмена и повтор — над сценарием слева. Справа вкладки «Показ» и «Заметки». Кнопка «Показать зрителям» остаётся рядом с навигацией под слайдом.

«Меню» объединяет проверку перед стартом, добавление файлов, пульт на телефоне, настройку заглушки, QR-код, настройки интерфейса и горячие клавиши. Лента страниц скрывается у материалов из одной страницы; лишняя кнопка следующего материала в конце файла не дублирует «Далее».

## Перед началом мероприятия

Откройте «Меню → Проверка перед стартом». Приложение проверит наличие файлов, заново прочитает первый слайд PDF/PPTX, изображения и метаданные аудио/видео, покажет количество экранов. Для потерянного файла доступна кнопка «Найти файл». Проверка запускается при закрытом экране зрителей.

«Тест экрана» выводит отдельную тестовую картинку на внешний монитор (или основной, если он один). Esc или щелчок закрывает тест. «Тест звука» воспроизводит короткий сигнал через выбранное в Windows устройство. Подтвердите, что изображение и звук попадают в зал. Автоматическая проверка не заменяет просмотр всех страниц и репетицию воспроизведения.

## Отмена изменений

Ctrl+Z отменяет, Ctrl+Shift+Z или Ctrl+Y повторяет изменение. Те же команды доступны кнопками над сценарием. История хранит до 50 изменений материалов, порядка, разделов, заметок, плейлистов и настроек мероприятия. Перелистывание и запуск/пауза воспроизведения в историю не входят. В текстовых полях действует обычная отмена ввода.

История относится только к открытому мероприятию и сбрасывается при переключении мероприятия или перезапуске приложения. Создание и удаление самих мероприятий не отменяется этой историей. Интерфейс настраивается отдельно.

## Полный и упрощённый интерфейс

Откройте «Меню → Настройки интерфейса». Упрощённый вид делает основные команды крупнее и скрывает часть дополнительных элементов. Можно отдельно включить или скрыть заметки, монитор зрителей, следующий слайд, ленту страниц, таймер, музыку, QR-код, телефонный пульт и режим подготовки.

Настройки интерфейса сохраняются на этом компьютере для всех мероприятий. При скрытии музыкального плеера воспроизведение останавливается. Кнопки проверки, настройки и управления показом остаются доступны. «Вернуть полный интерфейс» восстанавливает все элементы.

## Переходы и воспроизведение

Кнопка «Следующий материал» открывает следующий файл с начала. На последней странице команда «Далее» (стрелка вправо или пробел) делает то же самое. При управлении показом материал сразу отправляется зрителям; при подготовке меняется только выбор ведущего. Отсутствующий файл не пропускается молча — приложение сообщает о проблеме.

Выберите видео и откройте «Настройки видео». По умолчанию запуск ручной, после окончания остаётся последний кадр. Можно включить запуск при показе зрителям, повтор, настроить громкость и выбрать заглушку или следующий материал после окончания. Автоматический переход работает только при показе, а не при просмотре в подготовке. Повтор имеет приоритет над действием после окончания.

Во вкладке «Музыка» выберите длительность плавного включения и паузы: без затухания, 0,5 / 1 / 2 / 3 секунды. Кнопка настройки рядом с треком задаёт его громкость относительно общей. При начале видео музыка плавно затихает; после видео возвращается, только если до него играла. Настройки входят в пакет мероприятия.

## PPTX и ограничения

Первичный импорт PPTX требует установленного PowerPoint или WPS Office на Windows. Приложение готовит статическую PDF-копию. Пакет мероприятия включает эту копию, поэтому для её просмотра после переноса Office не требуется.

Анимации, переходы и встроенные в PPTX видео не воспроизводятся. Видео можно добавить отдельным материалом. Поддержка других операционных систем пока не проверена.

Телефон и компьютер должны находиться в одной доверенной локальной сети. Ссылка пульта даёт управление показом; не публикуйте её и не открывайте порт пульта в Интернет.

## Проверки

```sh
npm test
```

Тесты формата пакета проверяют перенос материалов, сохранение независимых записей, повреждение данных, некорректные пути и прерванные файлы. Пользовательские презентации и локальные тестовые профили в репозиторий не входят.

## Технологии

Electron, JavaScript, PDF.js, WebSocket и QRCode. Локальные файлы и настройки хранятся на компьютере пользователя.
