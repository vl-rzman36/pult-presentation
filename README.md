# Пульт — приложение для выступлений

Пульт помогает вести мероприятие с одного рабочего экрана: переключать презентации и видео, управлять фоновой музыкой и показывать зрителям отдельное окно без служебных заметок.

Текущая версия: **2.2.0**, Windows x64. Проект активно развивается.

## Возможности

- Мероприятия с отдельными материалами, заметками, плейлистами и настройками.
- Разделы сценария и перетаскивание материалов и разделов.
- PDF, изображения, отдельные видео и импорт PPTX.
- Экран ведущего и отдельный экран зрителей; предварительная подготовка следующего материала.
- Заглушка, заметки, миниатюры страниц и таймер.
- Музыкальные плейлисты: повтор, один трек и стоп, случайный порядок и другие режимы.
- Приостановка фоновой музыки на время видео.
- Пульт на телефоне через локальную сеть и QR-код.
- Экспорт мероприятия в файл `.pult` со всеми материалами и музыкой.

## Запуск

Скачайте ZIP со сборкой Windows из раздела **Releases**, распакуйте всю папку и запустите `PultPresentation.exe`. Установка Node.js для готовой сборки не нужна.

Для запуска из исходников нужны Windows и Node.js с npm:

```sh
npm ci
npm start
```

## Мероприятия и перенос

Список мероприятий находится сверху слева. Меню рядом позволяет создавать, переименовывать, копировать и удалять мероприятия, экспортировать и открывать пакеты. Изменения сохраняются автоматически.

Создайте разделы сценария и перетаскивайте материалы за ручку слева. Нажатие на название раздела открывает его название и заметку для редактирования.

Чтобы перенести выступление, экспортируйте `.pult` на флешку и откройте его в приложении на другом компьютере. Импорт копирует материалы локально, поэтому после завершения флешку можно отключить. Для переноса самого приложения скопируйте всю распакованную папку сборки.

Удаление материала из сценария не удаляет исходный файл с диска. Для переключения мероприятий закройте экран зрителей.

## PPTX и ограничения

Первичный импорт PPTX требует установленного PowerPoint или WPS Office на Windows. Приложение готовит статическую PDF-копию. Пакет мероприятия включает эту копию, поэтому для её просмотра после переноса Office не требуется.

Анимации, переходы и встроенные в PPTX видео не воспроизводятся. Видео можно добавить отдельным материалом. Поддержка других операционных систем пока не проверена.

Телефон и компьютер должны находиться в одной доверенной локальной сети. Ссылка пульта даёт управление показом; не публикуйте её и не открывайте порт пульта в Интернет.

## Проверки

```sh
npm test
```

Тесты формата пакета проверяют перенос материалов, сохранение независимых записей, повреждение данных, некорректные пути и прерванные файлы. Пользовательские презентации и локальные тестовые профили в репозиторий не входят.

## Технологии

Electron, JavaScript, PDF.js, WebSocket и QRCode. Локальные файлы и настройки хранятся на компьютере пользователя.
